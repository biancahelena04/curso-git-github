\##Fluxo de trabalho Git local

1. git checkout -b
2. cria ou atualiza arquivos
3. git status
4. git add arquivos
5. git status
6. git commit -m "minha mensagem"
7. git checkout main
8. git merge nova\_branch



\##Fluxo de trabalho GitHub <> Local (projeto próprio ou da sua empresa)



1. git clone
2. git checkout -b <nova\_branch>
3. alterações de arquivos
4. git status
5. git add arquivos
6. git status
7. git commit -m "nova mensagem"
8. git push origin <nova\_branch>
9. abrir Pull request no GitHub para main
10. excluir <nova\_branch> origin
11. git checkout main
12. git branch -D <nova\_branch>

##Fluxo de trabalho GitHub <> Local (projetos open-source)
13. Fork do projeto para seu próprio github
14. git clone
15. git checkout -b <nova\_branch>
16. alterações de arquivos
17. git status
18. git add arquivos
19. git status
20. git commit -m "nova mensagem"
21. git push origin <nova\_branch>
22. abrir Pull request no GitHub da branch fork para a main do projeto original
23. excluir <nova\_branch> origin
24. git checkout main
25. git branch -D <nova\_branch>
