git init . - cria um repo git na pasta atual
git status - mostra status do trabalho
git commit -m "msg" - faz commit do que estava para ser commitados
git add nome_arquivo - adiciona um arquivo a ser commitado
git log - mostra todo o histórico de commit
 
Fluxo de trabalho
1 criar diretório do projeto
2 iniciar o git no diretório
3 editar ou criar arquivos
4 git status
5 git add "nome arquivo" ou git add . ou git add * .txt
6 git status
7 git commit -m "mensagem"
8 git status
9 passo 3
